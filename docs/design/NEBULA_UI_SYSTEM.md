## 1. 产品理念

**Nebula 是一个可以走进去的音乐空间。** 曲库不是一张表，而是一片星云：每首歌是一颗带封面的星，你在其中漫游、拾取、聆听；音乐响起时，空间被它的颜色照亮，歌词在空气里流过。

同一个空间有三种状态：

| 状态 | 主角 | 其他元素 |
|---|---|---|
| 漫游 | 星云（封面卡片） | 歌词退后；界面安静 |
| 聆听 | 音乐带来的环境光 + 歌词 | 星云仍在，让出注意力 |
| 沉浸（听歌空间） | 歌词 / Orb | 主舞台退场（按播放器母稿） |

## 2. 六条原则

1. **颜色来自音乐。** 界面本身无色（中性光学材质），所有色彩都来自当前封面或背景媒体的采样。禁止硬编码品牌色或蓝色。
2. **玻璃是光学，不是油漆。** 材质由物理参数定义（散射、折射、色散、亮边、着色），禁止"刷一层带颜色的半透明底"。
3. **一次只有一个主角。** 星云、歌词、面板之间按状态交接注意力。
4. **深，而不是暗。** 用近黑底加远、中、近三层景深；景深靠光的衰减和空气透视表达，焦点区不加模糊。
5. **安静的界面，响亮的时刻。** 界面默认不发光、不乱动；表达集中在 §11 列出的少数签名时刻。
6. **字是声音的形状。** 歌词排版是一等设计面（衬线 + 单字强调）；界面文字用无衬线，克制分级。

## 3. 光学材质系统

### 3.1 一个模型，两个主题

磨砂（Frosted）和液态（Liquid）是**同一个光学模型的两组参数**，不是两套样式。组件只引用材质档位（§3.3），不写任何材质数值。

| 参数 | 含义 | CSS / 实现 |
|---|---|---|
| `tint` | 中性压暗（只用黑，不带色相） | `background: rgba(0,0,0, tint + tintAdapt)` |
| `tintAdapt` | 亮背景自适应加深（§3.4） | 0 – .22 |
| `blur` | 散射 | `backdrop-filter: blur()` |
| `refraction` | 边缘折射位移（px） | SVG 位移贴图，`scale = 2 × refraction` |
| `dispersion` | RGB 色散（%） | 三个通道的 scale 依次 × (1, 1 − d, 1 − 2d) |
| `rim` | 内侧亮边强度 | 三层 inset 阴影，见 §3.5 |
| `sat` | 透射增饱和 | `saturate()` |
| 亮度 | 固定 | `brightness(1.05)` |

**滤镜顺序（固定）**：`backdrop-filter: blur(var(--blur)) url(#glass-<id>) saturate(var(--sat)) brightness(1.05)`。
**必须**：如需 `-webkit-backdrop-filter`，写在无前缀属性**之前**；否则在 Chromium 里它会覆盖掉 `url()`，折射整体失效。

### 3.2 主题参数（已由用户目测确认）

| 主题 | refraction | dispersion | blur | rim | tint | sat |
|---|---|---|---|---|---|---|
| **液态（默认主题）** | 26px | 5% | 2.25px | .52 | 10% | 1.65 |
| 磨砂 | 6px | 0 | 16px | .40 | 8% | 1.40 |

- 液态的数值取自用户选定的「清透」与「均衡」中间值；接入真实界面后，桌面端验收时允许在 ±15% 内微调，调整结果回写本表。
- 切换入口沿用已有的「设置 → 系统设置 → 界面主题」（磨砂玻璃 / 液态玻璃），去掉"开发中"的禁用态。
- 低性能降级（§3.7）时，液态自动退回磨砂参数。

### 3.3 材质档位（按表面角色分）

| 档位 | 用在哪 | 液态主题 | 磨砂主题 |
|---|---|---|---|
| **G1 主玻璃** | 底部播放条、Dock 展开窗口、顶部搜索胶囊 | §3.2 液态全参数（含折射） | §3.2 磨砂 |
| **G2 透镜球** | Dock 小球、卡片 hover 时的播放球、回到中心等圆形按钮（≤ 48px） | 折射 ×0.6，色散 ×0.6，blur 1px，其余同液态 | 磨砂 |
| **G3 浓玻璃** | 大面：两侧面板、详情 / 歌手 / 评论弹窗；小弹层：队列 / 音量 / 音质、右键菜单、搜索结果、Toast、提示气泡 | **2026-11-13 起随主题切换（样张 G，用户确认）**：blur 14px，tint 22%，rim .55，sat 1.6；两侧面板只在边缘 24px 一圈折射 16px、色散 .03；弹窗和小弹层不折射（弹窗见下）；边缘受光高光（§3.5） | blur 18px，tint 28%，rim .40，sat 1.4；不折射，无受光高光（即原来的 G3） |

- **规则：新界面只选档位，不写材质数值。**每个浮在画面上的界面都声明自己是 G1、G2 还是 G3；主题切换时自动跟着变，不为每个界面单独设计两版。面板里的分组卡、列表行、滑轨、分段槽是"画在玻璃上的内容"，不随主题变。
- 液态 G3 的可读性底线：散射不低于 14px；亮背景加深按全额（§3.4）。
- 小弹层不折射：尺寸小，折射只会显脏。两侧面板固定 bezel 24px，不随面板高度变宽，中间区域完全不位移。
- 弹窗不折射（2026-11-13，#103）：背后是压暗 + 模糊的遮罩，边缘折射几乎看不见；而且用户桌面上打开评论弹窗出现整窗黑屏，本机复现不出来，最可能的原因是遮罩的背景滤镜和弹窗的折射滤镜叠在一起，所以撤掉这条路径。
- 原来"G3 不折射"的理由（尺寸一变就得重建贴图）已被九宫格贴图解决（§3.6），不再成立。
- **禁止玻璃套玻璃**：同一块玻璃内部不再嵌套玻璃面。弹层是独立的表面，不算嵌套。
- 遮罩（veil）：弹窗打开时，舞台整体 `brightness(.6) blur(6px)`，过渡 280ms。

### 3.4 亮背景自适应（必须实现）

- 环境亮度 `L` 取当前背景采样的平均亮度（§4.2 的 `lum`）。
- `tintAdapt = 0.22 × smoothstep(0.45, 0.70, L)`，过渡 800ms。
- 目的：浅色封面（例如白底封面）时，玻璃上的白字依然可读。界面文字始终保持白色，不切换成深色字。
- G1 / G2 / G3 都按全额加 `tintAdapt`。（G3 原来只加一半，2026-11-13 改为全额：浅色壁纸下，面板里的歌手名等 11–12px 小字原来偏淡。）

### 3.5 亮边与阴影（G1 / G2）

```css
box-shadow:
  inset 0 0 1.5px 1px rgba(255,255,255, calc(var(--rim) * .62)),
  inset 0 0 14px 3px rgba(255,255,255, calc(var(--rim) * .16)),
  inset 0 1px 0 rgba(255,255,255, calc(var(--rim) * .35)),
  0 2px 6px rgba(0,0,0,.22),
  0 22px 56px rgba(0,0,0,.34);
```

- 禁止常显的渐变描边（border-image 或渐变 border-box）、外发光、白色大面积渐变扫光。**唯一例外：液态 G3 的受光高光**（下一条）。
- G3：前两层 inset，外阴影换成 `0 12px 32px rgba(0,0,0,.4)`。
- **液态 G3 受光高光（样张 G，2026-11-13 用户确认）**：1px 渐变描边，光从左上来——155° 方向 `.5 → .1（22%）→ 0（48%）→ .05（78%）→ .24`；用 `::after` + mask 只画 1px 边，强度 `--g3-spec`（液态 1，磨砂和降级后 0）。只表现材质受光，不随 hover 变化，不加模糊不外扩，所以不算"发光"。另加一条 `inset 0 1px 0` 顶边高光。会自己滚动的弹层（播放队列）不画。

### 3.6 实现约定（GlassManager）

- 新增 `src/lib/glass/`：负责 SVG 滤镜容器、位移贴图生成和缓存。组件通过 `useGlass(ref, tier)` 注册。
- **P4 验收后修正（2026-11-12）：位移贴图改为九宫格**——4 个角块（R×R，R = max(圆角, bezel)）+ 4 条 1 像素边条（拉伸）+ feFlood 中性底，用 feMerge 合成。角块只取决于圆角与 bezel，边条只取决于离边距离，与宽度无关；尺寸变化时每一帧只改各块的 x / y / width / height（ResizeObserver 不防抖），高度或圆角变了才换图。原来按整块尺寸生成贴图、尺寸变化后防抖 120ms 重建，宽度动画中贴图停在旧尺寸：Dock 小球展开成胶囊时看得到"从球里拉出一个球头、到终点后猛地一变"。
- 贴图算法：
  - 表面轮廓用 convex squircle：`f(t) = (1 − (1 − t)^4)^(1/4)`；
  - 法线倾角 → 斯涅尔折射（n = 1.5）→ 横向位移 = `f(t) · tan(θ − θr)`，预先算成 256 档查找表并归一化；
  - bezel 宽度 = `min(高度 × 0.46, 30px)`；
  - 位移方向**向内**（只从玻璃内部取样）；
  - 编码：R = 128 − nx·m·127，G = 128 − ny·m·127，B = 128。
- 滤镜结构：一个 `feImage`，三次 `feDisplacementMap`（R / G / B 各一个 scale），`feColorMatrix` 分离通道，再两次 `feBlend mode="screen"` 合成。`color-interpolation-filters="sRGB"`。
- 缓存键：`角块边长 × 圆角 × bezel`（九宫格，2026-11-12 起；原来的 `宽 × 高 × 圆角 × bezel` + 防抖 120ms 重建已废弃）。
- 尺寸动画期间（例如底部条 → 听歌空间的变形）：先把三个 scale 动画到 0，变形结束后重建贴图，再把 scale 渐回去。只改 scale 不需要重建贴图。
- 每个 G1 / G2 表面各用一个滤镜 id；同尺寸的 G2 球共用一个滤镜。
- **G3 两侧面板注册折射（2026-11-13）**：`SideDock` 打开时调用 `useGlass(ref, 'g3')`，收起动画结束后注销；弹窗和小弹层不注册（弹窗原来也注册，#103 撤掉）。bezel 由 `materials.tierBezel()` 给出：G3 固定 24px，G1 / G2 仍是 `min(高度 × 0.46, 30px)`。贴图缓存键改为 `角块边长 × 圆角 × bezel`，G3 面板 / 弹窗高度变化不重画贴图。
- **G3 的材质画在元素本身**（与 G1 不同）：播放队列弹层自己是滚动容器，画在 `::before` 上会跟着内容滚走。代价是面板会成为内部元素的背景采样边界，面板里再套毛玻璃不生效（见 NOTES），面板里的浮层用遮罩淡出代替。
- **G1 / G2 的材质画在 `::before` 上，不画在元素本身**（P1 实施时发现）。带 `backdrop-filter` 的元素会成为它内部元素的"背景采样边界"：如果直接画在元素本身，嵌在里面、伸出边界的 G3 弹层（如播放条上的队列、音质、音量）就采不到背后的画面，模糊会失效。因此元素本身只需是定位元素并建立层叠上下文。

### 3.7 性能降级顺序

依次：色散 + G3 折射（G3 整体退回磨砂参数，面板折射面积最大，最先关）→ G2 折射 → G1 折射（退回磨砂参数）→ 环境光漂移（§4）。
始终保留：歌名 / 歌手、播放状态、当前歌词可读性、核心交互。
触发条件：连续 2 秒帧耗时 > 20ms，或用户在设置里开启「性能优先」。

**实现（P4，2026-11-12）**：`lib/perf.ts` 每 10 秒采样一次、每次 2 秒（只在窗口可见时，两次采样之间不占用帧）；一次采样平均帧耗时 > 20ms 且过半的帧 > 20ms 记为慢，**连续两次采样都慢才降一级**（导入歌单、切歌解码这类几秒的卡顿不误判）；本次运行内只降不升。档位：0 完整 → 1 关色散，G3 退回磨砂参数（2026-11-13 加入）→ 2 关 G2 折射 → 3 关 G1 折射、G1 / G2 退回磨砂参数 → 4 停环境光漂移与雾中封面呼吸。折射关掉时 `--glass-filter` 直接换成 `blur(0px)`，不再挂 SVG 滤镜。设置 → 系统设置 →「性能优先」直接到第 4 级；自动降级后说明文字会显示已降几级。

### 3.8 验收清单（每个用到玻璃的批次都要跑）

1. 深色封面和浅色封面两种背景下各看一遍：玻璃上的白字清楚。
2. 背后有复杂封面经过时：中间不糊成一团，边缘能看到弯折和轻微彩边。
3. 没有右侧缺块、整体偏移，也没有白色渐变扫光。
4. hover 任何按钮都没有光晕、圆盘或方框。
5. 星云漂移和拖拽时帧率稳定（空闲帧耗时 < 10ms，平移时 < 16ms）。

## 4. 环境（背景）

### 4.1 结构

从下到上：底色 `--ebase` → 三团环境光（大面积径向渐变）→ 胶片颗粒 → 暗角。全部是渐变，不用 `filter`。

| 层 | 规格 |
|---|---|
| 底色 | 深色封面：`mix(#050607, e1, 8%)`；浅色封面（`lum > .6`）：`mix(#050607, 主色, 10%)`，保持近黑。**P1 修正（2026-11-10，待用户桌面验收确认）**：原值 `mix(主色, #282a2e, 45%)` 会把整个空间铺成浅灰，正是审查时列出的旧问题 |
| 光团 b1 / b2 / b3 | 宽 78%，正圆，`radial-gradient(closest-side, color-mix(e, 72% / 60% / 52%), transparent)`；位置分别在左上外、右侧、下方外 |
| 漂移 | 34s / 41s / 47s，`ease-in-out infinite alternate`，位移 ≤ 14%，缩放 0.94 – 1.08 |
| 颗粒 | SVG feTurbulence 平铺，`opacity .07`，`mix-blend-mode: overlay` |
| 暗角 | `radial-gradient(120% 90% at 50% 45%, transparent 55%, rgba(0,0,0,.55))` |
| 换歌过渡 | 颜色变量用 `@property` 注册为 `<color>`，过渡 1.4s ease |

### 4.2 取色（替代现有 `coverColors` 的"三色"产出口径）

- 输入：当前背景媒体（封面 / 自定义图片 / 壁纸），缩到 32 × 32 后做 k-means（K = 6，迭代 10 次）。
- 每个色簇的得分 = `占比 × (0.25 + 1.6 × 饱和度) × (亮度在 .07–.93 之间 ? 1 : .25)`；按得分取 3 个色相或亮度明显不同的颜色。
- 环境光：三个颜色分别取 HSL 亮度 .46 / .40 / .36，饱和度上限 .80 / .75 / .70。
- 强调色 `--acc`：主色相，饱和度限制在 .45–.85，亮度固定 .72。
- 中性兜底：加权平均饱和度 < .12 时（黑白、灰调封面），环境光用 hsl(216, 6%, 50 / 40 / 32%)，强调色用 hsl(216, 14%, 82%)。
- 浅色封面（平均亮度 > .6）：环境光向白色混合 25–35%，变成淡色光，底色保持近黑（见 §4.1，P1 修正）。
- 明暗判断（§3.4 的自适应加深，以及歌词明暗）：「环境光」模式下用**渲染出来的环境亮度**（底色与主光团 45% 混合后的亮度），不用封面亮度。否则白色封面会让深色空间里的歌词变成深色字。其他模式（原图铺满等）仍用媒体本身的亮度。
- 产出：`{ e1, e2, e3, base, acc, lum, light }`，经 VisualAtmosphere 中间层下发（遵守 ARCHITECTURE 依赖规则：Background 不直接改 Lyrics）。

### 4.3 背景模式映射

| 现有模式 | 新行为 |
|---|---|
| 跟随封面 | 即 §4.1 的环境光（替换"封面放大模糊压暗铺满"）。**P4 定稿（2026-11-12，用户决定）**：只保留两种——**环境光**（默认）和**雾中封面**（原「混合层」重做，见下）。原图直铺、磨砂暗化、纯色纹理、仅取色、棱镜删除：前两种与星云抢主角或就是被取代的旧做法，后两种的颜色主要来自写死的兜底色而非封面，违反 §2 第 1 条。存储里的旧值迁移到环境光 |

### 7.1 漫游 / 聆听交接（2026-11-12 定稿，样张 D）

音乐在播放、用户静止一段时间后，界面从「漫游」切到「聆听」：星云让开，歌词成为主角。一动就回来。样张：<https://claude.ai/artifact/WCKeDcwXUmL99bLnKfBWLB>（私有）。

**三种让开方式全部保留，作为设置项由用户选择**（用户 2026-11-12 决定不三选一），默认「沉降」：

| 方式 | 聆听时（`--lk` = 1） | 歌词层 |
|---|---|---|
| **沉降**（默认） | 整片星云 `scale(.86)`（原点 50% 45%）+ `brightness(.38) saturate(.55)` | 歌词换到卡片之上；换层前先淡到 22%，换层后再亮起来，被挡住的半个字不会突然跳出来。歌词图层本来就是「卡片之上」时不换层、不淡 |
| **散开** | 卡片按离歌词区的远近向外推：椭圆中心 (50%, 37%)（「上下错落」布局时为 (50%, 50%)），半径 `rx = min(.4vw, .85vh)`、`ry = .38vh`；归一化距离 e 映射为 `e + k·.95·exp(−(e/.9)²)`（单调，卡片不会交换前后顺序；比样张取大，因为真实焦点卡片比样张大），景深按推开后的位置重新计算；被推开的卡片再压暗 `1 − .42·推开量`，整片星云 `brightness(.84)` | 不换层 |
| **退潮** | 整片星云不透明度降到 .14 | 不换层 |

**共用规则**

| 项 | 规格 |
|---|---|
| 进入 | 音乐在播放，鼠标、键盘、滚轮都静止 N 秒（设置：3 / 6 / 10，默认 6）。鼠标移出窗口、切到别的软件也算静止。条件不满足期间计时清零 |

| 回到漫游 | 鼠标累计移动超过 6px（400ms 内）、滚轮、按键、按下鼠标，立即回来。播放暂停、上述弹层打开时也回来 |
| 曲线 | 一个 0→1 的 `--lk`。进入 1.6s 缓入缓出（像灯光调暗）；回来 0.38s 缓出（不让人等）。中途反向时从当前值出发，时长按剩余距离缩短（最少 35%）。减少动态效果时直接切换 |

## 8. 星云卡片

### 8.1 外观

- **去掉相框**：删除卡片的 10px 内边距、渐变边框、背面错层基座（`::before`）和柔光遮罩（`::after`）。封面本身就是卡片：圆角 r-md（14px，随卡片缩放），阴影 `0 16px 38px rgba(0,0,0,.5)`。
- 标题和歌手放在封面**下方**，不加底板：标题 13 / 500 `--fg`，歌手 12 `--fg-2`，间距 10px。只在焦点圈内（距中心 < 45% 最大距离）或 hover 时显示，淡入淡出 300ms。
- 没有封面的歌曲：保留现有的 hue 渐变 + 黑胶占位，同样无框。

### 8.2 景深（替换 `fisheye.ts` 的模糊和亮度曲线，缩放曲线不变）

| 距中心 | 规则 |
|---|---|
| 焦点圈（< 32%） | `filter: none`（必须是 none，不能是 `blur(0.x)`） |
| 中圈 | 亮度 `1 − .5 × far`，饱和度 `1 − .35 × far`；其中 `far = clamp((t − .32) / .70, 0, 1)` |
| 外圈（> 82%） | 在上一行基础上叠加 `blur((t − .82) × 6px)`，最大约 1.1px |

`t` = 距离 ÷ 最大距离。中心亮度不再超过 1（删除原来的 1.12）。

### 8.3 Hover

沿用现有语义：**原地**转正 + 放大（沿用现有的 ×1.3 与 translateZ）+ 置顶 + 去模糊。
- 去掉白色边框、白色光晕和 `brightness(1.18)`；阴影加深到 `0 24px 60px rgba(0,0,0,.6)`。
- 放大不能把位移一起放大。实现上，卡片沿用同一条 `transform`，并把位移写在缩放之前（`translate3d(...) rotateZ(...) scale(...)`），效果等价于三者分开写。只有用独立的 `scale` 属性时才必须把三者拆开（样张 v1 的 bug 就是这样来的）。
- 封面上的播放按钮：改为 G2 透镜球（36px）+ 白色播放图形。

### 8.4 正在播放

封面四周一圈由它自己颜色形成的光，删除白色光晕。黑胶旋转仅保留在无封面的占位卡片上。

**P4 验收后修正（2026-11-12）**：光的强弱随封面本身（`--cover-sat` / `--cover-lum`，壁纸模式下也按当前封面单独取样）——不透明度 `clamp(.45, 饱和度×3, 1)`，亮度 `1.95 − .7×封面亮度`，灰白封面不再变成一团白雾；自定义图片 / 视频 / 壁纸背景（根节点 `data-bg-kind="media"`）上收紧成贴着封面的一圈：外扩 3%、`blur(26px)`、不透明度 `clamp(.1, 饱和度×1.6, .55)`，不在实景照片上铺开、不染到旁边的卡片。

**2026-11-12 修订（用户桌面验收反馈"光很淡很淡"）**：原写法是单色 `--acc` 投影（`0 30px 90px -18px …`），在与封面同色系的环境里几乎看不见，而且大部分被封面自己挡住。现改为：

- 用封面图本身做一层发光副本（`.cover-glow`），只给当前卡片渲染：比封面宽 16%、上移 6%，`filter: blur(46px) saturate(2.2) brightness(1.95)`，`translateY(5%) scale(1.1)`，层级在封面之下；
- 光的颜色就是封面的多种颜色，并且比环境更亮，所以同色系环境里也看得见；它以封面为中心向四周溢出，不沉到标题下面；
- 当前卡片的投影收轻（`0 10px 24px rgba(0,0,0,.32)`），免得把光压暗；标题阴影加深一点（`0 1px 2px .6` + `0 0 14px .45`）。

## 12. 禁止清单

- hover 圆形背景、外圈方框、通用发光；常显的渐变发光边框（液态 G3 的 1px 受光高光是唯一例外，见 §3.5）。
- 黑色塑料感的玻璃；带色相的半透明底；大面积白色渐变扫光；"Frosted = 最大模糊"。
- 硬编码蓝色或固定品牌色；装饰性粒子 / 星点。
- 卡片相框、卡片焦点区模糊。
- 玻璃套玻璃。
- 组件私设 z-index、裸写材质数值。
- 先做独立原型再搬进项目（样张只用于决策）。
- 歌词整句淡出消失、纯随机穿梭（沿用 LYRICS_SYSTEM）。
