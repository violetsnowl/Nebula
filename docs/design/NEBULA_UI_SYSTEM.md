## 1. 产品理念

**Nebula 是一个可以走进去的音乐空间。** 曲库不是一张表，而是一片星云：每首歌是一颗带封面的星，你在其中漫游、拾取、聆听；音乐响起时，空间被它的颜色照亮，歌词在空气里流过。

同一个空间有三种状态：

| 状态 | 主角 | 其他元素 |
|---|---|---|
| 漫游 | 星云（封面卡片） | 歌词退后；界面安静 |
| 聆听 | 音乐带来的环境光 + 歌词 | 星云仍在，让出注意力 |
| 沉浸（听歌空间） | 歌词 / Orb | 主舞台退场（按播放器母稿） |

## 2. 六条原则

1. **颜色来自音乐。** 界面本身无色（中性光学材质），所有色彩都来自当前封面或背景媒体的采样。禁止硬编码品牌色或蓝色。
2. **玻璃是光学，不是油漆。** 材质由物理参数定义（散射、折射、色散、亮边、着色），禁止"刷一层带颜色的半透明底"。
3. **一次只有一个主角。** 星云、歌词、面板之间按状态交接注意力。
4. **深，而不是暗。** 用近黑底加远、中、近三层景深；景深靠光的衰减和空气透视表达，焦点区不加模糊。
5. **安静的界面，响亮的时刻。** 界面默认不发光、不乱动；表达集中在 §11 列出的少数签名时刻。
6. **字是声音的形状。** 歌词排版是一等设计面（衬线 + 单字强调）；界面文字用无衬线，克制分级。

## 3. 光学材质系统

### 3.1 一个模型，两个主题

磨砂（Frosted）和液态（Liquid）是**同一个光学模型的两组参数**，不是两套样式。组件只引用材质档位（§3.3），不写任何材质数值。

| 参数 | 含义 | CSS / 实现 |
|---|---|---|
| `tint` | 中性压暗（只用黑，不带色相） | `background: rgba(0,0,0, tint + tintAdapt)` |
| `tintAdapt` | 亮背景自适应加深（§3.4） | 0 – .22 |
| `blur` | 散射 | `backdrop-filter: blur()` |
| `refraction` | 边缘折射位移（px） | SVG 位移贴图，`scale = 2 × refraction` |
| `dispersion` | RGB 色散（%） | 三个通道的 scale 依次 × (1, 1 − d, 1 − 2d) |
| `rim` | 内侧亮边强度 | 三层 inset 阴影，见 §3.5 |
| `sat` | 透射增饱和 | `saturate()` |
| 亮度 | 固定 | `brightness(1.05)` |

**滤镜顺序（固定）**：`backdrop-filter: blur(var(--blur)) url(#glass-<id>) saturate(var(--sat)) brightness(1.05)`。
**必须**：如需 `-webkit-backdrop-filter`，写在无前缀属性**之前**；否则在 Chromium 里它会覆盖掉 `url()`，折射整体失效。

### 3.2 主题参数（已由用户目测确认）

| 主题 | refraction | dispersion | blur | rim | tint | sat |
|---|---|---|---|---|---|---|
| **液态（默认主题）** | 26px | 5% | 2.25px | .52 | 10% | 1.65 |
| 磨砂 | 6px | 0 | 16px | .40 | 8% | 1.40 |

- 液态的数值取自用户选定的「清透」与「均衡」中间值；接入真实界面后，桌面端验收时允许在 ±15% 内微调，调整结果回写本表。
- 切换入口沿用已有的「设置 → 系统设置 → 界面主题」（磨砂玻璃 / 液态玻璃），去掉"开发中"的禁用态。
- 低性能降级（§3.7）时，液态自动退回磨砂参数。

### 3.3 材质档位（按表面角色分）

| 档位 | 用在哪 | 液态主题 | 磨砂主题 |
|---|---|---|---|
| **G1 主玻璃** | 底部播放条、Dock 展开窗口、顶部搜索胶囊 | §3.2 液态全参数（含折射） | §3.2 磨砂 |
| **G2 透镜球** | Dock 小球、卡片 hover 时的播放球、回到中心等圆形按钮（≤ 48px） | 折射 ×0.6，色散 ×0.6，blur 1px，其余同液态 | 磨砂 |
| **G3 浓玻璃** | 弹层（队列 / 音量 / 音质）、右键菜单、搜索结果、Toast、设置窗口、详情 / 歌手 / 评论弹窗 | 不折射；blur 18px，tint 28%，rim .40，sat 1.4 | 同左 |

- G3 不折射的理由：弹层要开合动画，尺寸一变就得重建贴图；而且承载长文字，可读性优先。
- **禁止玻璃套玻璃**：同一块玻璃内部不再嵌套玻璃面。弹层是独立的表面，不算嵌套。
- 遮罩（veil）：弹窗打开时，舞台整体 `brightness(.6) blur(6px)`，过渡 280ms。

### 3.4 亮背景自适应（必须实现）

- 环境亮度 `L` 取当前背景采样的平均亮度（§4.2 的 `lum`）。
- `tintAdapt = 0.22 × smoothstep(0.45, 0.70, L)`，过渡 800ms。
- 目的：浅色封面（例如白底封面）时，玻璃上的白字依然可读。界面文字始终保持白色，不切换成深色字。

### 3.5 亮边与阴影（G1 / G2）

```css
box-shadow:
  inset 0 0 1.5px 1px rgba(255,255,255, calc(var(--rim) * .62)),
  inset 0 0 14px 3px rgba(255,255,255, calc(var(--rim) * .16)),
  inset 0 1px 0 rgba(255,255,255, calc(var(--rim) * .35)),
  0 2px 6px rgba(0,0,0,.22),
  0 22px 56px rgba(0,0,0,.34);
```

- 禁止常显的渐变描边（border-image 或渐变 border-box）、外发光、白色大面积渐变扫光。
- G3 只用前两层 inset，外阴影换成 `0 12px 32px rgba(0,0,0,.4)`。

### 3.6 实现约定（GlassManager）

- 新增 `src/lib/glass/`：负责 SVG 滤镜容器、位移贴图生成和缓存。组件通过 `useGlass(ref, tier)` 注册。
- 贴图算法：
  - 表面轮廓用 convex squircle：`f(t) = (1 − (1 − t)^4)^(1/4)`；
  - 法线倾角 → 斯涅尔折射（n = 1.5）→ 横向位移 = `f(t) · tan(θ − θr)`，预先算成 256 档查找表并归一化；
  - bezel 宽度 = `min(高度 × 0.46, 30px)`；
  - 位移方向**向内**（只从玻璃内部取样）；
  - 编码：R = 128 − nx·m·127，G = 128 − ny·m·127，B = 128。
- 滤镜结构：一个 `feImage`，三次 `feDisplacementMap`（R / G / B 各一个 scale），`feColorMatrix` 分离通道，再两次 `feBlend mode="screen"` 合成。`color-interpolation-filters="sRGB"`。
- 缓存键：`宽 × 高 × 圆角 × bezel`。尺寸变化后防抖 120ms 再重建。
- 尺寸动画期间（例如底部条 → 听歌空间的变形）：先把三个 scale 动画到 0，变形结束后重建贴图，再把 scale 渐回去。只改 scale 不需要重建贴图。
- 每个 G1 / G2 表面各用一个滤镜 id；同尺寸的 G2 球共用一个滤镜。

### 3.7 性能降级顺序

依次：色散 → G2 折射 → G1 折射（退回磨砂参数）→ 环境光漂移（§4）。
始终保留：歌名 / 歌手、播放状态、当前歌词可读性、核心交互。
触发条件：连续 2 秒帧耗时 > 20ms，或用户在设置里开启「性能优先」。

### 3.8 验收清单（每个用到玻璃的批次都要跑）

1. 深色封面和浅色封面两种背景下各看一遍：玻璃上的白字清楚。
2. 背后有复杂封面经过时：中间不糊成一团，边缘能看到弯折和轻微彩边。
3. 没有右侧缺块、整体偏移，也没有白色渐变扫光。
4. hover 任何按钮都没有光晕、圆盘或方框。
5. 星云漂移和拖拽时帧率稳定（空闲帧耗时 < 10ms，平移时 < 16ms）。

## 4. 环境（背景）

### 4.1 结构

从下到上：底色 `--ebase` → 三团环境光（大面积径向渐变）→ 胶片颗粒 → 暗角。全部是渐变，不用 `filter`。

| 层 | 规格 |
|---|---|
| 底色 | 深色封面：`mix(#050607, e1, 8%)`；浅色封面（`lum > .6`）：`mix(主色, #282a2e, 45%)` |
| 光团 b1 / b2 / b3 | 宽 78%，正圆，`radial-gradient(closest-side, color-mix(e, 72% / 60% / 52%), transparent)`；位置分别在左上外、右侧、下方外 |
| 漂移 | 34s / 41s / 47s，`ease-in-out infinite alternate`，位移 ≤ 14%，缩放 0.94 – 1.08 |
| 颗粒 | SVG feTurbulence 平铺，`opacity .07`，`mix-blend-mode: overlay` |
| 暗角 | `radial-gradient(120% 90% at 50% 45%, transparent 55%, rgba(0,0,0,.55))` |
| 换歌过渡 | 颜色变量用 `@property` 注册为 `<color>`，过渡 1.4s ease |

### 4.2 取色（替代现有 `coverColors` 的"三色"产出口径）

- 输入：当前背景媒体（封面 / 自定义图片 / 壁纸），缩到 32 × 32 后做 k-means（K = 6，迭代 10 次）。
- 每个色簇的得分 = `占比 × (0.25 + 1.6 × 饱和度) × (亮度在 .07–.93 之间 ? 1 : .25)`；按得分取 3 个色相或亮度明显不同的颜色。
- 环境光：三个颜色分别取 HSL 亮度 .46 / .40 / .36，饱和度上限 .80 / .75 / .70。
- 强调色 `--acc`：主色相，饱和度限制在 .45–.85，亮度固定 .72。
- 中性兜底：加权平均饱和度 < .12 时（黑白、灰调封面），环境光用 hsl(216, 6%, 50 / 40 / 32%)，强调色用 hsl(216, 14%, 82%)。
- 浅色封面（平均亮度 > .6）：环境光向白色混合 45–55%，同时触发 §3.4 的自适应加深。
- 产出：`{ e1, e2, e3, base, acc, lum, light }`，经 VisualAtmosphere 中间层下发（遵守 ARCHITECTURE 依赖规则：Background 不直接改 Lyrics）。

### 4.3 背景模式映射

| 现有模式 | 新行为 |
|---|---|
| 跟随封面 | 即 §4.1 的环境光（替换"封面放大模糊压暗铺满"） |
| 自定义图片 / Wallpaper | 媒体本身铺满 + 暗角；用媒体取色驱动强调色与 `tintAdapt` |
| 午夜（兜底） | 中性环境光（§4.2 兜底色）；**星点默认移除** |

### 5.5 层级（禁止组件私设 z-index）

| L1 | 10 | Z1 歌词（"歌词在卡片之上"模式时为 30） |
| L2 | 20 | 星云舞台（内部自行排序） |
| L3 | 40 | 底部播放条、顶栏、回到中心 |
| L4 | 50 | 左右 Dock |
| L5 | 60 | G3 弹层（队列、音量、音质、右键菜单、搜索结果） |
| L6 | 70 / 80 | 弹窗遮罩 / 弹窗 |
| L7 | 90 | Toast |
| L8 | 100 | Tooltip |

调试用的界面不得进入生产构建。

## 6. 交互状态语言（全局）

| 状态 | 规则 |
|---|---|
| Hover（图标、文字按钮） | **由元素自身呈现**：颜色 `.66 → 1.0`；图形缩放 1.07（只作用于 svg 或文字本身，不作用于容器），d-std + ease-jelly。**无容器底色、无光晕、无圆盘、无方框。** |
| Hover（列表行） | 文字提亮到 `--fg` + 整行极淡底色 `rgba(255,255,255,.05)`（无描边）；当前项用 `--acc` 文字 + 左侧 2px `--acc` 指示条 |
| Hover（卡片） | 见 §8.3 |
| 按下 | 图形缩放 .93，d-instant |
| Focus | 仅键盘焦点（`:focus-visible`）：2px `rgba(255,255,255,.55)` 描边，偏移 2px，圆角跟随元素。鼠标点击不出现焦点框 |
| 禁用 | `--fg-disabled`，无 hover 反馈 |
| 选中（分段控件） | 选中段底 `rgba(255,255,255,.08)` + 1px 内描边 `rgba(255,255,255,.07)` |

**发光授权**：全局只有两类元素允许持续发光，因为它们表达"正在发生"：
1. 正在唱的那个字（§7）；
2. 正在播放那张卡片下方、由封面颜色形成的环境光（§8）。

其余一切发光都禁止，包括 hover 光晕、常显边框发光、文字自发光。

**必须删除**：`src/styles.css` 中的全局 `button:hover / .glass-btn:hover / [role=button]:hover` 光晕规则（第 3733 行、第 4035 行附近），以及重复定义的 `.glass-btn`。

## 7. 歌词（Z1 字体层）

运动、三身份、生命周期、安全区沿用 `LYRICS_SYSTEM.md`，**不改**。本节只规定字。

| 项 | 规格 |
|---|---|
| 字体 | Display / 歌词字体栈，600 |
| 当前句字号 | `clamp(34px, 5.4vw, 78px) × currentScale`（沿用现有设置项） |
| 下一句 / 下下句 | 当前句的 .50 / .36 倍；整句颜色 `rgba(255,255,255,.60)` |
| 字距 | `.05em` |
| 未唱 | `rgba(255,255,255,.34)` |
| 已唱 | `rgba(255,255,255,.96)` |
| 正在唱 | `--acc`，`text-shadow: 0 0 22px color-mix(in srgb, var(--acc) 55%, transparent)`，上移 2px |
| 扫字 | 保留现有连续进度 `--wp` 和软羽化；渐变为三段：已唱白 → 波前 `--acc` → 未唱 .34。只有波前带颜色 |
| 浅色背景可读性 | 整层加中性外羽化：`drop-shadow(0 1px 2.4px rgba(4,6,12,.58)) drop-shadow(0 0 4.8px rgba(4,6,12,.30))`；不给字形内部染灰 |
| 翻译 | Z1 仍不显示翻译（沿用） |

设置映射：现有 `lyricColorSource: 'cover' | 'custom'` 保留。`cover` = 本节默认值；`custom` 时，用户自定义的主色映射到"已唱"，高亮色映射到"正在唱"。
`highlightStyle: 'sweep' | 'float'` 保留，`float` 即"正在唱上移 2px + 已唱微弹"。

## 8. 星云卡片

### 8.1 外观

- **去掉相框**：删除卡片的 10px 内边距、渐变边框、背面错层基座（`::before`）和柔光遮罩（`::after`）。封面本身就是卡片：圆角 r-md（14px，随卡片缩放），阴影 `0 16px 38px rgba(0,0,0,.5)`。
- 标题和歌手放在封面**下方**，不加底板：标题 13 / 500 `--fg`，歌手 12 `--fg-2`，间距 10px。只在焦点圈内（距中心 < 45% 最大距离）或 hover 时显示，淡入淡出 300ms。
- 没有封面的歌曲：保留现有的 hue 渐变 + 黑胶占位，同样无框。

### 8.2 景深（替换 `fisheye.ts` 的模糊和亮度曲线，缩放曲线不变）

| 距中心 | 规则 |
|---|---|
| 焦点圈（< 32%） | `filter: none`（必须是 none，不能是 `blur(0.x)`） |
| 中圈 | 亮度 `1 − .5 × far`，饱和度 `1 − .35 × far`；其中 `far = clamp((t − .32) / .70, 0, 1)` |
| 外圈（> 82%） | 在上一行基础上叠加 `blur((t − .82) × 6px)`，最大约 1.1px |

`t` = 距离 ÷ 最大距离。中心亮度不再超过 1（删除原来的 1.12）。

### 8.3 Hover

沿用现有语义：**原地**转正 + 放大（沿用现有的 ×1.3 与 translateZ）+ 置顶 + 去模糊。
- 去掉白色边框、白色光晕和 `brightness(1.18)`；阴影加深到 `0 24px 60px rgba(0,0,0,.6)`。
- 位置用独立的 `translate` 属性，转正用 `rotate`，放大用 `scale`，三者分开写，确保放大不会把位移一起放大。
- 封面上的播放按钮：改为 G2 透镜球（36px）+ 白色播放图形。

### 8.4 正在播放

封面下方一圈由它自己颜色形成的光：`0 30px 90px -18px color-mix(in srgb, var(--acc) 70%, transparent)`。删除白色光晕。黑胶旋转仅保留在无封面的占位卡片上。

## 12. 禁止清单

- hover 圆形背景、外圈方框、通用发光；常显的渐变发光边框。
- 黑色塑料感的玻璃；带色相的半透明底；大面积白色渐变扫光；"Frosted = 最大模糊"。
- 硬编码蓝色或固定品牌色；装饰性粒子 / 星点。
- 卡片相框、卡片焦点区模糊。
- 玻璃套玻璃。
- 组件私设 z-index、裸写材质数值。
- 先做独立原型再搬进项目（样张只用于决策）。
- 歌词整句淡出消失、纯随机穿梭（沿用 LYRICS_SYSTEM）。
