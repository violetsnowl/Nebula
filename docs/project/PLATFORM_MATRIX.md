# 平台 × 功能完成度表

> 用途：一眼看出五个平台在每一项后端功能上是否完整。规则：**每个格子都必须有内容可显示**；优先用本平台，本平台没有或失败时由其他平台兜底，并标出来源。只要有一格是「❌ → ❌」，就是缺陷。
>
> 首版：2026-11-17（主线 b559f88 之后，后端重构 #141–#156 合入后），依据代码核对加用户真实账号副本实测。每补一个缺口都要回来改这张表。

## 怎么读

- 格子写法：**本平台 → 兜底**。
  - 例：`✅ → ❌` 表示本平台能取，本平台失败时没有兜底。
  - 例：`❌ → 网易云/QQ` 表示本平台没有，靠网易云、QQ 补。
- ✅ 已实现并实测；☑️ 已实现但没有实测过；⚠️ 有问题或只做了一半；❌ 空白；— 不适用。
- 「同一录音」：标题、全部歌手、版本一致，时长差 ≤2–6 秒（`recordingMatch.ts`）。
- 当前兜底优先级按会员档位自动排：网易云（超级会员）→ QQ（超级会员）→ 酷狗（免费）。

## 缺陷清单（按影响排）

1. **评论**：酷狗、汽水、Spotify 完全没有；网易云、QQ 本平台失败时为空。
   - 改法：本平台没有或失败时，按同一录音去网易云 → QQ 取评论，界面标注来源。
2. **歌曲详情**：同上。
   - 改法：按同一录音去网易云 → QQ 取。
3. **Spotify 登录**：整列账号功能不可用，连歌单导入也不行。
   - 改法一：像 folia 那样用 Spotify 桌面客户端的身份登录，不用注册。
   - 改法二：你自己注册 Spotify 开发者应用，开发模式最多 5 个用户。
4. **Spotify 逐字歌词**。
   - 改法：兜底的歌词如果来自「同一录音」，就信任它的逐字时间轴。
   - 再加一个歌词源：社区维护的逐字歌词库 AMLL TTML DB（folia 在用）。
5. **专辑页**：网易云、QQ 本平台失败时为空。改法：按专辑名兜底。
6. **汽水取链**。
   - 改法：接 `qishui-music-api`（MIT，folia 在用，走车机协议），只有标准音质。
   - 需要单独用抖音扫码授权。
7. **会员识别**：酷狗把已有的会员查询接到登录信息上，进兜底排序；汽水补查会员。
8. **QQ 登录自动续期**。
9. **汽水罗马音**：补全的触发条件加上「外语歌缺罗马音」。
10. **搜索**：汽水、Spotify 接入搜歌；酷狗接入搜歌手。
